#  Algoritmos e Estruturas de Dados

Repositório destinado aos estudos, exercícios e atividades desenvolvidos na disciplina de **Algoritmos e Estruturas de Dados** durante o curso de **Engenharia de Software**.

##  Sobre a disciplina

A disciplina aborda conceitos fundamentais para a organização, armazenamento e manipulação de dados em programas, utilizando diferentes estruturas de dados e algoritmos.

Durante os estudos, são trabalhados conceitos como:

*  Listas
*  Pilhas (Stack)
*  Filas (Queue)
*  Filas circulares
*  Filas de prioridade
*  Busca e manipulação de elementos
*  Ordenação
*  Complexidade de algoritmos
*  Notação Big O
*  Algoritmos e resolução de problemas

## 💻 Linguagem utilizada

Os exercícios deste repositório são desenvolvidos principalmente em:

* **Python**

## Objetivo

Este repositório tem como objetivo registrar minha evolução no aprendizado de **algoritmos e estruturas de dados**, colocando em prática os conceitos estudados por meio de exercícios e pequenos sistemas.

Além de servir como material de estudo, o projeto também faz parte da construção do meu portfólio acadêmico e profissional.
